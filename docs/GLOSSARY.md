# Glossary

- **Report** — a price value for a feed at a round, carrying a signer and a payload hash.
- **Bonus** — the liquidator's profit above principal and fees; the only value Lantern holds.
- **Hold window** — the interval in which a held bonus may be contested.
- **Prover** — the party opening a challenge; posts a stake, receives a bounty if upheld.
- **Self-history band** — the acceptable range derived from a feed's own realized moves.
- **Exposure** — the sum of held bonuses on liquidations that consumed a given feed.
- **Exposure floor** — the minimum bond a feed must post for its current exposure.
- **Waterfall** — payout order on an upheld challenge: borrower, prover, bond.
- **Shortfall queue** — FIFO remainder parked against a feed when a payout exceeds the bond.
